# Network Packet Sniffer

Explore sample packet metadata and learn how network traffic is described.

## Run
Open index.html in a modern browser. For File Protection Utility and Cryptographic Encryption Vault, run through localhost (for example VS Code Live Server) to enable Web Crypto. Uses fictional packet metadata, not live packet capture.

## Technology
HTML, CSS and vanilla JavaScript.

## Safety
Educational demonstration only. Do not use as a production security control or enter sensitive real-world data.
